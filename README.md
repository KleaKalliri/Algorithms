# Graph Algorithms in Java

A collection of Java implementations of directed graph algorithms, covering traversal, cycle detection, topological ordering, strongly connected components, and Eulerian cycles.

## Contents

| File | Description |
|---|---|
| `Digraph.java` | Directed graph representation. |
| `Degrees.java` | In-degree and out-degree calculations for graph vertices. |
| `DirectedDFS.java` | Depth-first search for directed graphs. |
| `DepthFirstOrder.java` | Vertex ordering based on depth-first traversal. |
| `DirectedCycle.java` | Cycle detection in directed graphs. |
| `Topological.java` | Topological ordering of directed acyclic graphs. |
| `KosarajuSharirSCC.java` | Kosaraju–Sharir algorithm for identifying strongly connected components. |
| `DirectedEulerianCycle.java` | Eulerian cycle detection and construction in directed graphs. |

## Purpose

This repository explores fundamental graph algorithms and their implementation in Java. It serves as a reference for studying graph structures, connectivity, traversal, and ordering.

## Language

Java
